# Hotel Price Comparator

A Python script that compares your hotel pricing against competitors daily and tells you when you are over or under the market.

## The problem it solves

Hotel managers manually check competitor prices and struggle to spot pricing patterns over time. This script does the analysis automatically.

## How to use it

1. Fill in your daily prices in `precios.xlsx`
2. Double-click `ejecutar.bat`
3. Check `comparativa_precios.xlsx` for the results

No coding needed on your end.

## What it shows

- Day by day comparison with competitor prices
- Whether you are cheaper, more expensive or equal each day
- Average prices for both you and competitors
- Summary of how many days you were above or below market

## Setup

Requires Python 3 and pandas:

pip install pandas openpyxl
